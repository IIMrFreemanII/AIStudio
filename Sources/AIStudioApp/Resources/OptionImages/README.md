Example photos for the character creator's look options, made with OptionImageMaker
(`--smoke-characters-real <any> --smoke-real-option-images --smoke-real-out <dir>`) and copied here.
File names: `<category>-<option>-<gender>.jpg`.

The current set is drawn by MiniMax H3 Image with the chosen model faces:
`--smoke-real-art minimax --smoke-real-faces scripts/option-models` (about $0.011 a picture on a B200).
